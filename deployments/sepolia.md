sources. Compiler settings are in `hardhat.config.js` and are what make the
build reproducible: **solc 0.8.24, optimizer enabled, `runs: 200`, evmVersion
cancun**.

`MilestoneEscrow` has no fixed address. The factory deploys one per project,
and only escrows it created are recorded in `isOfficialEscrow` — which is the
whole reason the two contracts were merged. Do not deploy one by hand.

The build id above was regenerated by `npx hardhat compile --force` after the
deployment and produced **the same hash**, which is what confirms these
addresses correspond to these sources at these settings.

### Not yet verified on Etherscan

`ETHERSCAN_API_KEY` in `.env` is still the `.env.example` placeholder, so
`npx hardhat verify` returns `Invalid API Key`. Source verification is worth
doing — this contract asks people to lock funds in it, and unverified bytecode
means taking that on trust. Get a free key from etherscan.io, then:

    npx hardhat verify --network sepolia 0x1f8978Df2681C9F65714fcb12101F328C760e4dC
    npx hardhat verify --network sepolia 0x427A2618c0A9251cc7a71058510c9197b2914249 0x8E1371C3748709C924a1605aD850da7626B8799f 150
